# Spec Delta

## Purpose

Позволяет сохранить результат вычислительного эксперимента в C++ и повторно построить его графики в Python из одного переносимого файла.

## ADDED Requirements

### Requirement: Метаданные и массивы хранятся в одном архиве

Архив эксперимента MUST содержать один JSON-манифест с версией схемы, видом эксперимента и описанием массивов, а также именованные NPY-массивы. Результат MUST полностью загружаться из этого файла.

#### Scenario: Архив перемещён на другой компьютер

- **WHEN** оператор копирует готовый архив в другую папку или на другой компьютер
- **THEN** Python загружает метаданные и численные массивы из архива без обращения к исходной папке C++

#### Scenario: Массивы разных форм

- **WHEN** C++ сохраняет вектор, прямую траекторию и матрицу сдвигов
- **THEN** Python восстанавливает тип элементов, форму, порядок и значения отсчётов каждого массива, включая пустой массив с известным числом координат

### Requirement: C++ публикует завершённый архив

C++ MUST завершить запись и сохранить архив на диске до попытки подключения к серверу. Запись MUST сохранять ранее опубликованные результаты и сообщать об ошибке сохранения.

#### Scenario: Сервер выключен

- **WHEN** расчёт завершён, а отправка отключена или сервер недоступен
- **THEN** завершённый архив доступен для офлайн-отрисовки

#### Scenario: Запись завершилась ошибкой

- **WHEN** архив не удалось полностью записать или сохранить по конечному пути
- **THEN** C++ сообщает об ошибке, сохраняет прежние результаты и не начинает отправку

### Requirement: Архив задаёт входы отрисовки

Архив MUST содержать фактические численные данные графика, включая временную ось там, где она используется. Для каждого запрошенного графика MUST поддерживаться стабильный идентификатор вида и необязательные текстовые заголовок и подписи осей.

#### Scenario: Повторное построение с заданным заголовком

- **WHEN** архив запрашивает фазовый портрет и петлю гистерезиса с отдельными заголовками
- **THEN** Python выбирает соответствующие функции отрисовки, передаёт им сохранённые данные и применяет заголовок и подписи каждого графика

#### Scenario: Параметры оформления опущены

- **WHEN** архив запрашивает поддерживаемый график без заголовка или подписей
- **THEN** отрисовка использует стандартное оформление этого вида графика

### Requirement: Загрузчик отклоняет повреждённые и неизвестные архивы

Загрузчик MUST проверять поддерживаемую версию, поля манифеста, наличие и совместимость указанных массивов до отрисовки. Чтение архивного содержимого MUST оставаться в пределах контейнера и поддерживать только численные NPY-массивы.

#### Scenario: Неизвестная версия или повреждённые данные

- **WHEN** загружаемый архив содержит неизвестную версию, отсутствующий массив, несогласованную форму или повреждённые данные
- **THEN** загрузчик сообщает причину отказа и не запускает отрисовку

#### Scenario: Неизвестный вид графика

- **WHEN** манифест запрашивает неподдерживаемый вид графика
- **THEN** загрузчик сообщает об ошибке без вызова функции отрисовки
