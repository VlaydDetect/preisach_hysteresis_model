## Проверка крупного набора

Серия `PreisachModel/BifurcationDiagram_A.json` содержит 800 значений параметра и матрицу отсчётов формы `800 × 18850 × 2`. Один локальный замер под Windows x64 сравнивал загрузку JSON с переводом в NumPy и загрузку ZIP, записанного C++ с несжатыми NPY. Время измерено без отрисовки, память — пиковый рабочий набор отдельного Python-процесса. Состояние файлового кэша не фиксировалось.

| Формат | Размер, МиБ | Чтение, с | Пиковая память, МиБ |
| --- | ---: | ---: | ---: |
| JSON | 576.10 | 12,93 | 3035.30 |
| ZIP с NPY | 230.11 | 0,159 | 261.35 |

Формы и SHA-256 бинарного представления всех значений `float64` совпали. C++-клиент передал 241 287 467 байт локальному Python-серверу при лимите 1 073 741 824 байт. SHA-256 сохранённого на сервере архива совпал с исходным ZIP.
