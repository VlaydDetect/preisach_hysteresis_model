# Spec Delta

## Purpose

Закрепляет контракт размерностей состояния и результатов интегрирования и анализа динамических систем для C++-потребителей.

## ADDED Requirements

### Requirement: Размерность системы является частью её типа

Публичный API динамической системы MUST задавать положительную размерность состояния `N` при компиляции. Начальные условия, текущее состояние, правая часть и векторы возмущений MUST иметь `N` компонент, якобиан MUST иметь форму `N × N`. Если граница API принимает динамический объект, она MUST проверять форму до преобразования в фиксированный тип.

#### Scenario: Совместимые системы и решатели

- **WHEN** потребитель создаёт двумерную систему Радонса или Дуффинга либо трёхмерную систему Лоренца и передаёт её в общий решатель
- **THEN** решатель использует соответствующую размерность состояния и якобиана без отдельного параметра размерности во время выполнения

#### Scenario: Ошибка фиксированной размерности

- **WHEN** потребитель передаёт трёхкомпонентное начальное состояние, вектор возмущения или якобиан `3 × 3` для двумерной системы
- **THEN** вызов отклоняется при компиляции

#### Scenario: Ошибка на границе с динамической размерностью

- **WHEN** потребитель передаёт динамический объект неверной формы через поддерживаемую границу импорта состояния или параметров, связанных с размерностью системы
- **THEN** API сообщает об ошибке размера до изменения состояния либо начала вычислений

#### Scenario: Двумерный алгоритм

- **WHEN** потребитель передаёт трёхмерную систему в алгоритм шаттл-пойнта
- **THEN** вызов отклоняется при компиляции

### Requirement: Траектория сохраняет ось координат

Возвращаемые типы траекторий MUST фиксировать ось координат в типе и определять длину траектории по числу отсчётов во время выполнения. Порядок отсчётов и ориентация осей MUST соответствовать контракту соответствующего метода.

#### Scenario: Прямое интегрирование

- **WHEN** потребитель строит прямую траекторию или пару прямых траекторий
- **THEN** каждая матрица имеет `N` столбцов, а строки содержат отсчёты по времени

#### Scenario: Сдвиг траектории

- **WHEN** потребитель рассчитывает траекторию сдвига для начальной точки
- **THEN** матрица имеет `N` строк, а столбцы содержат отсчёты по времени

### Requirement: Численная сопоставимость экспериментов

При одинаковых исходных условиях, шаге, параметрах и состоянии модели библиотека MUST сохранять численное поведение интегрирования и действующие форматы результатов экспериментов.

#### Scenario: Сравнение с зафиксированным эталоном

- **WHEN** потребитель воспроизводит эталонные расчёты Радонса и Лоренца и параметризованный расчёт петли гистерезиса
- **THEN** формы, порядок отсчётов и поля экспорта совпадают с эталоном, а значения укладываются в заданные для этих расчётов допуски

#### Scenario: Повторный запуск расчёта сечения Пуанкаре

- **WHEN** потребитель вычисляет сечение или стробоскопическое отображение для валидной системы
- **THEN** расчёт начинает интегрирование после сброса состояния и завершает вызов с живой системой, состояние которой снова сброшено
